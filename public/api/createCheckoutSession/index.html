POST/v1/checkout

Create a checkout session

Create a hosted checkout session for a price and redirect the customer to the returned URL.

Authentication requiredCheckoutopenapi/vessel.json
Open request preview ↗JSON operation ↗

Parameters

Idempotency-Keyheader · required

A stable key for safely retrying the same checkout request.

Request example

{
  "price": "price_basic",
  "success_url": "https://example.com/success"
}

Success response · 201

{
  "id": "cs_123",
  "url": "https://checkout.example.com/cs_123",
  "status": "open"
}
